Questions fréquentes

Utilisez la barre de recherche ou les filtres pour trouver votre réponse.

DémarrageComment créer un compte sur ESTRA LINK ?

Cliquez sur « Créer un compte » sur la page d'accueil, puis remplissez le formulaire : nom, post-nom, prénom, numéro de téléphone (ou email), mot de passe, et type de compte (élève / étudiant / enseignant).

Si vous avez moins de 15 ans, le nom et le téléphone d'un parent ou tuteur sont obligatoires.

DémarrageJ'ai oublié mon mot de passe, que faire ?

Sur la page de connexion, cliquez sur « Mot de passe oublié ». Vous recevrez un code de réinitialisation par SMS ou par email selon votre méthode d'inscription.

Le lien de réinitialisation est valable 30 minutes. Si vous ne recevez rien, vérifiez vos spams ou contactez support@estra-link.com.

DémarrageComment modifier mes informations de profil ?

Allez dans Paramètres → Profil depuis le menu principal. Vous pouvez y modifier votre avatar, votre bio, votre établissement, votre filière et vos centres d'intérêt.

Le nom et le prénom sont verrouillés après inscription pour des raisons de sécurité : contactez le support pour les changer.

CompteComment activer l'authentification à deux facteurs (2FA) ?

Rendez-vous dans Paramètres → Sécurité → 2FA. Vous pouvez choisir entre :

  • Code par SMS (+243)
  • Application d'authentification (Google Authenticator, Authy...)

Nous recommandons fortement l'activation, surtout si vous êtes enseignant ou tuteur.

CompteJ'ai été piraté, que faire immédiatement ?

Agissez vite :

  • Changez votre mot de passe depuis un appareil sûr
  • Activez la 2FA depuis les paramètres de sécurité
  • Déconnectez toutes les sessions depuis Paramètres → Sécurité
  • Écrivez à support@estra-link.com avec l'objet « COMPTE PIRATÉ »

Notre équipe peut bloquer temporairement votre compte le temps de sécuriser l'accès.

CompteComment supprimer définitivement mon compte ?

Depuis Paramètres → Confidentialité → Supprimer mon compte. Une double confirmation vous sera demandée.

La suppression est irréversible : profil, publications, messages, progression et certificats sont effacés sous 30 jours (sauvegardes techniques incluses).

CoursLes cours sont-ils gratuits ?

Oui. L'accès de base est gratuit pour tous les apprenants. Certains contenus avancés (certifications officielles, formations premium) pourront être payants à l'avenir, mais le cœur de la plateforme reste gratuit.

CoursComment obtenir un certificat ?

Un certificat est délivré lorsque vous terminez :

  • 100 % des leçons d'un cours
  • Les quiz et exercices avec un score minimum de 70 %

Votre certificat est nominatif, infalsifiable, et téléchargeable en PDF depuis votre profil.

MessagesComment fonctionnent les suggestions de binômes ?

L'algorithme propose des profils compatibles avec le vôtre en se basant sur :

  • Vos centres d'intérêt
  • Votre filière et niveau scolaire
  • Vos relations en commun

Aucune donnée sensible (ethnie, religion, santé, opinions) n'est utilisée. Vous pouvez désactiver les suggestions dans Paramètres → Confidentialité.

MessagesPourquoi la messagerie est-elle désactivée avec certains utilisateurs ?

Par mesure de protection des mineurs, la messagerie est désactivée entre un adulte et un mineur non binôme. Cette règle s'applique systématiquement et ne peut pas être désactivée.

Si vous pensez qu'il s'agit d'une erreur, contactez support@estra-link.com.

NotificationsPourquoi je ne reçois pas mes notifications push ?

Vérifiez ces trois points :

  • L'autorisation des notifications dans votre navigateur ou OS
  • Vos préférences dans Paramètres → Confidentialité
  • Le mode « Ne pas déranger » de votre téléphone

Sur certains navigateurs (Safari iOS notamment), les push nécessitent d'ajouter ESTRA LINK à l'écran d'accueil.

NotificationsComment gérer mes préférences de notification ?

Dans Paramètres → Confidentialité, vous pouvez activer ou désactiver séparément :

  • Notifications push
  • Emails (sécurité, cours, marketing)
  • SMS critiques

Les notifications de sécurité (nouvelle connexion, changement de mot de passe) restent toujours actives.

ConfidentialitéComment exporter mes données personnelles ?

Depuis Paramètres → Confidentialité → Télécharger mes données. Vous recevrez un fichier JSON contenant :

  • Votre profil
  • Vos consentements
  • Vos publications et commentaires
  • Votre progression dans les cours

L'export est disponible immédiatement pour les données de base, et sous 24 h pour les données volumineuses.

ConfidentialitéQui peut voir mon profil ?

Cela dépend de vos paramètres. Par défaut :

  • Adultes : profil visible par tous les membres
  • Mineurs : profil privé par défaut (visible par vos contacts uniquement)

Vous pouvez ajuster ces paramètres à tout moment depuis Paramètres → Confidentialité.

ConfidentialitéComment exercer mes droits sur mes données ?

Vous disposez de droits d'accès, de rectification, d'effacement, de portabilité, d'opposition et de limitation. Contactez le DPO : dpo@estra-link.com — réponse sous 30 jours.

La plupart des actions (export, suppression, consentements) sont directement accessibles dans Paramètres → Confidentialité. Consultez la Politique de confidentialité pour tous les détails.

SignalementComment signaler un contenu inapproprié ?

Chaque publication, commentaire, message et profil dispose d'un bouton « Signaler » (icône drapeau). Sélectionnez le motif et ajoutez un commentaire si nécessaire.

Vous pouvez aussi écrire à contact@estra-link.com. L'identité du signaleur reste strictement confidentielle.

SignalementQue se passe-t-il après un signalement ?

Notre équipe de modération examine chaque signalement sous 48 à 72 h (priorité absolue pour les cas graves : contenu impliquant un mineur, menace imminente).

Selon la gravité, nous pouvons : avertir l'utilisateur, retirer le contenu, suspendre temporairement ou définitivement le compte, et/ou signaler aux autorités compétentes.

ParentsMon enfant a moins de 15 ans, comment l'inscrire ?

L'inscription d'un mineur de moins de 15 ans nécessite votre consentement explicite. Pendant l'inscription de votre enfant, renseignez :

  • Votre nom complet
  • Votre numéro de téléphone (+243)

Vous recevrez un SMS de confirmation et pourrez à tout moment demander la suppression du compte de votre enfant.

ParentsComment superviser le compte de mon enfant ?

Pour les mineurs, les protections suivantes sont actives automatiquement :

  • Profil privé par défaut
  • Messagerie restreinte avec les adultes
  • Aucune publicité ciblée
  • Filtrage des contenus inappropriés

Un espace tuteur complet est en cours de développement pour vous permettre de gérer les autorisations.

ParentsComment supprimer le compte de mon enfant ?

Écrivez à dpo@estra-link.com en précisant :

  • Le nom d'utilisateur de votre enfant
  • Votre nom et votre numéro de téléphone (celui enregistré à l'inscription)
  • Le motif de la demande

La suppression est traitée sous 7 jours ouvrés, sans justification à fournir au-delà.

Aucun résultat trouvé Essayez un autre mot-clé ou contactez le support.

Dépannage rapide

Les problèmes les plus courants et leurs solutions immédiates.

La page ne se charge pas

Vérifiez votre connexion Internet. Essayez de recharger avec Ctrl+Shift+R (ou Cmd+Shift+R sur Mac). Videz le cache de votre navigateur si le problème persiste.

Impossible de se connecter

Vérifiez que votre clavier n'est pas en majuscules. Utilisez « Mot de passe oublié » si nécessaire. Si votre compte est bloqué, contactez le support.

Mes messages ne s'envoient pas

Vérifiez votre connexion. Si le destinataire vous a bloqué, le message échouera silencieusement. Essayez de recharger la conversation.

L'application est lente ou plante

Fermez les autres onglets gourmands. Mettez à jour votre navigateur. Sur mobile, désinstallez/réinstallez la PWA. Si le problème persiste, signalez-le à support@estra-link.com.
